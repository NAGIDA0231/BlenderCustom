# BlenderCustom

Blender の操作・表示を、Unity などに慣れた人向けにカスタマイズするアドオンです。
キーの割り当て・範囲選択・浮かぶパネル・テーマの色などを 1 つのアドオンにまとめています。

- 対象バージョン: Blender 5.3（4.2 以降で動く想定）
- アドオンを無効にすると、キーの割り当て・テーマの色・プリファレンスは元に戻ります

## インストール

1. このリポジトリを clone します。

   ```bash
   git clone https://github.com/NAGIDA0231/BlenderCustom.git C:\Blender
   ```

2. Blender のアドオンフォルダから、`blender_custom` フォルダへのリンク（ジャンクション）を作ります。
   PowerShell で実行します（`5.3` は使っている Blender のバージョンに合わせます）。

   ```powershell
   New-Item -ItemType Junction -Path "$env:APPDATA\Blender Foundation\Blender\5.3\scripts\addons\blender_custom" -Target "C:\Blender\blender_custom"
   ```

3. Blender の「編集 > プリファレンス > アドオン」で「BlenderCustom」にチェックを入れます。

更新するときは `git pull` してから Blender を再起動します。

## 機能

### 視点の操作

| 操作 | 動き |
| :-- | :-- |
| 右ボタンを押しながらドラッグ | 視点の回転 |
| 右クリック（ドラッグせずに離す） | コンテキストメニュー |
| 中ボタンを押しながらドラッグ | 平行移動 |
| F1 / Shift+F1 | 右側面 / 左側面 |
| F2 / Shift+F2 | 頭上 / 下 |
| F3 / Shift+F3 | 正面 / 背面 |

視点の切り替えはアニメーションなしで一瞬で行い、ドラッグしても透視投影・平行投影が勝手に切り替わらないようにしています。

### 選択

| 操作 | 動き |
| :-- | :-- |
| 投げ縄・ボックス選択（ドラッグ） | 編集モードでは、完全に囲んだ頂点・辺・面だけを選ぶ。裏側に隠れているものも選ぶ |
| 1 / 2 / 3 | 頂点・辺・面の選択モードを個別にオン・オフ |
| Shift + 1 / 2 / 3 | そのモードだけにする |
| ヘッダーの選択モードのアイコン | クリックで個別にオン・オフ、Shift+クリックでそのモードだけ |
| Ctrl+A | 全選択 |
| Ctrl+D | 全選択されていなければ全選択、されていれば全解除。オブジェクトモードではアウトライナーで選んでいるコレクションが対象 |
| マウスを乗せる（編集モード） | 頂点・辺・面を黄色くハイライト（裏向きの面は対象外） |

### メッシュの編集（編集モード）

| 操作 | 動き |
| :-- | :-- |
| Delete | 確認メニューを出さずに削除（面選択なら面、辺なら辺、それ以外は頂点） |
| Ctrl+C / Ctrl+X / Ctrl+V | 選んだ面・辺・頂点のコピー / 切り取り / 同じ位置への貼り付け |
| Ctrl+J | 選んだ頂点を中心にマージ |

### 浮かぶパネル

3D ビューの上に表示され、タイトルバーをドラッグすると動かせます（位置はアドオン設定に保存）。

- **Edit Panel**: 移動・拡大・回転を、全方向または X / Y / Z 軸ごとに行うボタン。ボタンの上で押したままドラッグし、離すと確定します。
- **QuickPanel**: よく使う切り替えのボタン。
  - 選択: 投げ縄 ⇔ ボックス（移動ツールなどの使用中は、ヘッダーの「ドラッグ」の設定を切り替え）
  - モディファイア: 表示 ⇔ 非表示（選んでいるオブジェクトのモディファイアをまとめて）

### テーマの色

| 対象 | 色 |
| :-- | :-- |
| 編集モードの未選択の頂点・辺 | ピンク |
| 編集モードの選択中の頂点・辺・面 | 水色 |
| オブジェクトの選択の輪郭 | 水色（アクティブは明るい水色） |

## キーの割り当てを外した標準機能

| キー | 標準の機能 | 代わりの呼び出し方 |
| :-- | :-- | :-- |
| Ctrl+A（オブジェクトモード） | 適用メニュー | ヘッダーの「オブジェクト > 適用」 |
| Ctrl+A（ポーズモード） | ポーズの適用 | ヘッダーの「ポーズ > 適用」 |
| Ctrl+X（編集モード） | 溶解 | X キーの削除メニュー |
| Ctrl+V（編集モード） | 頂点メニュー | ヘッダーの「頂点」メニュー |
| Delete（編集モード） | 削除メニュー | X キー |
| F1 / F2 / F3（3D ビュー上） | マニュアル / 名前の変更 / メニュー検索 | 3D ビュー以外では標準のまま |

## 構成

| ファイル | 内容 |
| :-- | :-- |
| `blender_custom/__init__.py` | アドオンの入口。モジュールの登録順 |
| `keymaps.py` | キーの割り当て |
| `theme.py` | テーマの色とプリファレンス |
| `preferences.py` | アドオン設定（パネル位置など） |
| `listener.py` | マウス操作を受け取る共通の仕組み |
| `floating_panel.py` | 浮かぶパネルの共通部品 |
| `edit_panel.py` / `quick_panel.py` | 各パネル |
| `enclosed_select.py` | 完全に囲んだものだけを選ぶ投げ縄・ボックス選択 |
| `hover_highlight.py` | マウスを乗せた要素のハイライト |
| `select_mode_icons.py` | ヘッダーの選択モードのアイコンの差し替え |
| `select_all_toggle.py` | Ctrl+D の切り替え |
| `mesh_delete.py` / `mesh_clipboard.py` | Delete キー / コピー・切り取り・貼り付け |

QuickPanel にボタンを追加するときは、`quick_panel.py` に `label` / `is_on` / `execute` を持つクラスを作り、`QUICK_ITEMS` に足します。
